# Getting Started with Next.js 14

Next.js has revolutionized the way we build React applications. In this comprehensive guide, we'll explore the key features of Next.js 14 and how to get started with your first project.

## Why Next.js?

Next.js provides several benefits out of the box:
- Server-Side Rendering (SSR)
- Static Site Generation (SSG)
- App Router
- API Routes
- TypeScript Support
- Built-in Image Optimization

## Getting Started

First, create a new Next.js project:

```bash
npx create-next-app@latest my-next-app
cd my-next-app
```

### Project Structure

Your Next.js project will look something like this:

```plaintext
my-next-app/
├── app/
│   ├── layout.tsx
│   └── page.tsx
├── public/
├── components/
├── package.json
└── tsconfig.json
```

## Working with App Router

The App Router is one of the most powerful features in Next.js 14. Here's a basic example:

```typescript
// app/page.tsx
export default function Home() {
  return (
    <main>
      <h1>Welcome to Next.js</h1>
    </main>
  );
}
```

## Server Components

Next.js 14 introduces Server Components as the default. Here's how to use them:

```typescript
// app/users/page.tsx
async function getUsers() {
  const res = await fetch('https://api.example.com/users');
  return res.json();
}

export default async function UsersPage() {
  const users = await getUsers();
  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```
